# ELIZA MVP

Simple clickable MVP for acute referral management with local demo state only.

## Run locally

Open [index.html](/Users/lizzie/Documents/Codex%20Eliza/index.html) directly in a browser for a quick preview, or serve the folder locally:

```bash
cd "/Users/lizzie/Documents/Codex Eliza"
python3 -m http.server 4173
```

Then visit `http://127.0.0.1:4173`.

## What is included

- Homepage with ELIZA positioning and CTA routes
- GP dashboard, add referral flow, and GP referral detail with updates
- Specialty dashboard and specialty action flow
- GP and specialty audit pages
- Demo-only referral data stored in `localStorage`

## Demo notice

Demo only. No real patient data. Not connected to NHS systems.
